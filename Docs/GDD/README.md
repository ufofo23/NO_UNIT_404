# GDD — 설계 문서

이 폴더 바로 아래에 있는 파일이 **현재 기준**이고, `archive/` 는 이전 버전이다.
코드와 숫자는 항상 현재 기준 문서를 따른다.

| 버전 | 파일 | 상태 |
|---|---|---|
| **v5.1** | [NO_UNIT_404_GDD_v5.1.md](NO_UNIT_404_GDD_v5.1.md) | **현재 기준** — 시나리오 v2.1 정본 편입, B1~6F 고정, 솔로 우선, 단일 엔딩 |
| v5.0 | [archive/NO_UNIT_404_GDD_v5.0.md](archive/NO_UNIT_404_GDD_v5.0.md) | 보관 — 솔로 우선 / 상태 기반 랜덤 / 단일 엔딩 |

v1.0 · v2.1 · v3.0 은 이 저장소에 들어온 적이 없다. `CLAUDE.md` 와 일부 코드 주석이
그 문서들의 절 번호를 가리키고 있지만 파일은 여기에 없다.

## 새 버전을 올릴 때

1. 지금 기준 문서를 `git mv` 로 `archive/` 에 옮긴다. 복사하지 않는다 — 기준 문서는 한 벌이다.
2. 새 파일을 이 폴더에 `NO_UNIT_404_GDD_v<버전>.md` 이름으로 넣는다.
3. 위 표에 한 줄을 추가하고 "현재 기준" 표시를 옮긴다.
4. `CLAUDE.md` 의 Source of truth 와 `Docs/ONBOARDING.md` 의 경로를 같은 커밋에서 고친다.

보관본은 고치지 않는다. 이전 버전에서 무엇이 달랐는지 확인하는 용도다.
