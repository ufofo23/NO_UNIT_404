# 등급분류 준비 자료 (국내)

## 0. 이 문서의 성격과 한계

이 문서는 **등급분류 신청서에 붙일 내용 기술 자료**다. 게임의 실제 내용을 GDD와
구현된 콘텐츠에서 그대로 뽑아 정리한 것이므로, 심의 서식에 옮겨 적는 데 바로 쓸 수
있다.

**법적 판단은 담겨 있지 않다.** 어떤 경로로 신청해야 하는지, 자체등급분류사업자를
경유할 수 있는지, 해외 플랫폼 단독 출시에 어떤 예외가 적용되는지는 제도가 계속
바뀌는 영역이고 잘못 판단하면 출시 자체가 막힌다. **게임물관리위원회(GRAC)에 직접
문의하거나 국내 퍼블리셔·법률 자문을 통해 확인할 것.** 아래 "신청 경로" 절은 확인해야
할 질문 목록이지 답이 아니다.

심의는 기간이 걸리므로 **아트/오디오 패스와 병행해서 가장 먼저 시작**하는 것이 맞다.
등급분류에는 완성 빌드가 아니라 내용을 확인할 수 있는 빌드와 영상이면 되는 경우가
많다.

## 2. 줄거리 요약

플레이어는 해솔아파트 103동의 임시 야간 관리원 윤서우다. 전임 관리원 박동식이 실종된
뒤 6일간의 야간 근무를 맡는다. 관리실 PC로 CCTV·주민 DB·출입 기록을 확인하고,
인터폰으로 찾아온 방문자의 신원을 판별하고, 민원이 들어온 층을 직접 순찰한다.

건물에는 도면상 존재하지 않는 404호가 있고, 그곳에서 죽은 아이 윤하린의 흔적이 남아
있다. 플레이어가 모은 증거를 어떻게 판정하고 무엇을 기록으로 남기는지에 따라 5개의
엔딩 중 하나에 도달한다.

## 3. 내용정보 서술 (심의 항목별)

심의 서식의 7개 항목 순서를 따른다. 각 항목은 **게임에 실제로 존재하는 표현**만
기술한다.

### 3.1 선정성 — 없음

- 성적 표현, 노출, 성적 대상화가 전혀 없다.
- 등장인물 9명 전원 일상복 차림이며 신체를 강조하는 연출이 없다.
- 연애 요소 없음.

### 3.2 폭력성 — 낮음

- **전투 시스템이 없다.** 무기, 적 체력, 공격 수단이 설계 단계에서 제외되어 있다
  (GDD 3.3 / 2.2).
- 위협 상황은 추격과 은신으로만 구성된다. 플레이어가 붙잡히면 시간을 잃고 그 밤의
  평가가 떨어질 뿐, 신체 훼손 묘사가 없다.
- 과거에 발생한 화재와 아동 사망이 서사의 중심이지만, **직접 노출하지 않는다.**
  GDD 4.4가 이를 제작 원칙으로 명시한다:
  > 시신과 화상 묘사는 직접 노출보다 실루엣, 소리, 기록으로 전달한다.
- 유혈 표현, 신체 절단, 고어 없음.

### 3.3 공포 — 높음 (등급 결정 요인)

- 심리 호러가 이 게임의 핵심 장르다.
- CCTV 이상현상 36종, 정전 상황, 야간 순찰 중 추격 구간이 주요 공포 연출이다.
- **점프 스케어를 의도적으로 제한한다.** 오디오 설계(GDD 19.3)가 코드 수준에서
  강제한다: 가장 큰 소리도 일반 환경음 대비 **+8dB를 넘지 못하며**, 이 규칙은
  `AudioService`의 믹스 정책과 `AudioPolicyTests` 자동 테스트로 검증된다.
- 갑작스러운 최대 음량 연출이 존재하지 않는다.
- 초자연 존재(윤하린)는 **플레이어를 이유 없이 공격하지 않는다** (GDD 4.4).

**접근성 완화 수단이 게임 내에 있다** — 심의 시 참고 자료로 제출할 수 있다:

| 옵션 | 효과 |
|---|---|
| 밤을 느리게 | 압박 상승 0.5배, 대면 시 시간 손실 절반 |
| 추격 난이도 완화 | 추격 구간 난이도 하향 |
| 모션 감소 | 화면 흔들림 억제 |
| 카메라 흔들림 | 0~100% 조절 |
| 밝기 보정 | 75~150% |
| 환경음 자막 | 소리 단서를 텍스트로 제공 |
| 스트리머 모드 | 밝기 상향 포함 |

### 3.4 약물 — 없음

- 음주, 흡연, 약물 사용 묘사 없음.

### 3.5 범죄 — 낮음

- 과거에 벌어진 사건(화재 은폐, 기록 조작, 실종)이 조사 대상으로 다뤄진다.
- 플레이어는 범죄를 **저지르는 쪽이 아니라 기록하고 판정하는 쪽**이다.
- 범죄 수법을 학습 가능한 형태로 구체 묘사하지 않는다.
- 단, 플레이어가 기록을 삭제하거나 은폐를 선택할 수 있으며(엔딩 B/C), 이 선택은
  **부정적 결과로 귀결되도록 설계**되어 있다.

### 3.6 언어 — 낮음

- 욕설, 비속어 없음.
- 갈등 상황의 고성과 위협적 어조가 있으나 수위가 높지 않다.
- 정신질환을 공포의 원인으로 사용하지 않는다 (GDD 4.4 명시 원칙).

### 3.7 사행성 — 없음

- 확률형 아이템 없음.
- 인게임 재화, 인앱 결제, 유료 뽑기 없음.
- 도박 소재 없음.
- **1회 구매 후 추가 결제 요소가 전혀 없다.**

## 4. 등급 판단 근거 요약

**15세 이용가**로 판단한 근거:

1. 공포 표현의 강도와 지속성이 전체 플레이의 중심이다 → 전체이용가·12세는 어렵다.
2. 아동 사망이 서사의 핵심 소재다 → 12세 이용가에는 부적합.
3. 그러나 **직접적 시각 묘사가 없고**(3.2), 유혈·고어·선정성·사행성이 전무하며,
   점프 스케어가 설계·코드 양쪽에서 제한된다 → 청소년이용불가 요소가 없다.

비교 대상: 유사 장르 국내 서비스작(관찰·이상현상 신고 계열, 심리 호러 어드벤처)이
대체로 12세~15세 구간에 분포한다.

## 5. 신청 경로 — 확인해야 할 사항

아래는 **결정된 사항이 아니라 GRAC 또는 자문에 확인할 질문 목록**이다.

- [ ] Steam 단독(해외 플랫폼) 출시에 국내 등급분류 의무가 어떻게 적용되는지
- [ ] 자체등급분류사업자 경유가 가능한지, 가능하다면 어느 사업자인지
- [ ] GRAC 직접 신청 시 필요 서류·수수료·소요 기간
- [ ] 1인 개발자/개인사업자 신분으로 신청 가능한지, 사업자등록이 선행되어야 하는지
- [ ] 데모 빌드(GDD 29장)를 별도 등급분류해야 하는지
- [ ] 등급 표시 의무 — 스토어 페이지와 게임 내 어디에 어떻게 표기해야 하는지
