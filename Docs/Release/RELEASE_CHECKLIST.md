# 출시 체크리스트

**이 문서의 목적은 "아트만 하면 끝"이 아니라는 것을 한 장으로 보여주는 것이다.**

코드와 콘텐츠 층은 사실상 끝나 있다. 남은 것은 크게 셋이다 — 아트/오디오, **대기 시간이
있는 행정 절차**, 그리고 **아직 아무도 처음부터 끝까지 플레이해보지 않았다는 사실**.

세 번째가 가장 위험하고, 두 번째가 가장 늦게 시작하기 쉽다.

---

## 0. 지금 당장 시작해야 하는 것 (대기 시간이 있다)

**아트를 기다리지 말 것.** 아래는 그레이박스 상태로도 진행되고, 늦게 시작하면 아트가
끝난 뒤에도 그만큼 더 기다린다.

| 항목 | 대기 | 왜 지금인가 |
|---|---|:---|
| **Steam Direct 등록** | 결제 후 **30일** | $100 결제 시점부터 시계가 돈다. 게임 완성도와 무관하게 흐른다 |
| **GRAC 등급분류** | 수 주 | 완성 빌드가 아니라 **내용 확인용 빌드와 영상**이면 되는 경우가 많다 (`RATING_GRAC.md` 0절) |
| **사업자 등록 여부 판단** | 가변 | Steam 정산 세금 정보의 **선행 조건**이다. 미정이면 결제도 못 받는다 |

`RATING_GRAC.md` 5절은 신청 경로가 **결정된 사항이 아니라 확인해야 할 질문 목록**이라고
명시한다. 그 확인부터가 리드타임이다.

### 1.1 이번에 닫은 갭

- **품질 프리셋 3종** (GDD 16.16) — 낮음/보통/높음, 각각 전용 URP 에셋.
  이전에는 `Mobile`/`PC` 2단계였고 `Mobile`이 Standalone을 제외하고 있어서
  **Windows 빌드에서 실제로 고를 수 있는 프리셋이 하나뿐**이었다.
  옵션 화면도 엔진 레벨 이름을 그대로 노출해 한국어 UI에 `Mobile` / `PC`가 찍혔다.
  이제 `ui.quality.*` 로컬라이즈 키를 쓴다. `GraphicsPresetTests`가 3단계와 순서를 잡는다.
- **스토커 저작 순찰 경로** (GDD 9.6 / 15.2) — 존별 사각형 루프를 제거했다.
  주차장은 계단문 → 차단기 → 남측 소방차로의 미등록 차량 → 기록실 문으로 도는 14노드
  회로, 기록실은 선반과 서버랙에 멈추는 5노드 회로다.
  기록실에서 **멈추지 않으면** 6×5 방을 8초마다 한 바퀴 돌아 은신 캐비닛이 무용지물이
  되므로, GDD 9.6이 말하는 "기록을 회수하러 들어온" 행동을 체류 시간으로 구현했다.
  `PatrolRouteTests`가 모든 구간을 지오메트리에 대조한다.
- **지오메트리 단일 출처** — `BasementLayout.cs`. 월드 배치와 순찰 경로가 같은 테이블을
  읽으므로 둘이 어긋날 수 없다.
- **Steam App ID 단일 상수** — `NO404.Core.SteamAppInfo`. 이전에는 플랫폼 제한 어셈블리
  안에 있어서 **릴리스 점검이 볼 수 없었다.** 이제 480이면 BLOCKING으로 잡힌다.

## 5. QA — **가장 큰 미확인 리스크**

문서 어디에도 **사람이 릴리스 빌드로 6일차까지 완주한 기록이 없다.**

테스트 163개와 `Simulate Nights`는 로직을 잡는다. 잡지 못하는 것은 소프트락, 페이싱,
그리고 "3일차에서 뭘 해야 할지 모르겠다" 같은 것들이다. 4~6시간짜리 조사 게임에서
이것들은 테스트가 아니라 사람만 찾아낸다.

- [ ] **본인이 릴리스 빌드로 프롤로그 → 6일차 완주 1회** (다섯 결말 중 하나)
- [ ] 나머지 4개 결말 도달 경로 확인
- [ ] **외부 플레이테스트 3~5명** — 최소한 프롤로그와 1일차. 튜토리얼 이해도가 목적
- [ ] 세이브 손상 복구 경로 확인 — 개발자 콘솔 `save.corrupt_test`
- [ ] 5개 해상도에서 UI 확인 (GDD 28.6)
- [ ] **최소 사양 기기에서 성능 측정** — `Tools ▸ NO404 ▸ Release ▸ Measure Performance`.
      이 툴은 **에디터 Play 모드에서만** 동작하므로 배치로 돌릴 수 없다. 그리고 개발 PC
      (RTX 4060 Ti)에서 잰 값은 최소 사양 근거가 되지 않는다 — 두 가지 이유로 이 항목은
      사람이 최소 사양 기기에서 해야 한다
- [ ] 품질 프리셋 3단계가 실제로 다르게 보이는지 육안 확인

## 6. 권장 순서

```
지금            ─ Steam Direct 결제(30일 시계) · GRAC 문의 · 사업자 판단
  │
  ├─ 병렬 ─────  아트 패스 ────────────────┐
  ├─ 병렬 ─────  오디오 패스 (음악/보이스) ─┤
  └─ 병렬 ─────  본인 완주 1회 + 외부 테스트 3~5명
                                            │
아트/오디오 완료 후 ────────────────────────┘
  ├─ 스크린샷 · 트레일러 · 캡슐 6종
  ├─ App ID 교체 + 파트너 사이트 설정 전체
  ├─ 최소 사양 성능 측정 → 시스템 요구사항 확정
  └─ Release Readiness Report BLOCKING 0 → 업로드
```

**아트에 3개월을 쓴 뒤 0절을 시작하면, 출시는 아트 완료 시점보다 한두 달 더 밀린다.**
0절은 오늘 시작할 수 있고, 오늘 시작해야 한다.
