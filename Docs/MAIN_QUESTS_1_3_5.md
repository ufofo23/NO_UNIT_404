# 1·3·5일차 메인 퀘스트

기준: `NO_UNIT_404_GDD_v5.1.md`, `CHARACTER_CARDS_v2_0.md`.
기존 Unity 그레이박스와 사건·증거·저장 시스템에 연결했다. 캐릭터 카드 열람 화면과 다른 일자의 퀘스트는 이번 구현 범위에 포함하지 않는다.

## 테스트 플레이

개발 콘솔에서 `dev.mainonly on`을 실행한 다음 `night.start 1`, `night.start 3`, `night.start 5`로 해당 근무를 시작한다. 메인만 테스트하는 모드는 기존 개발용 기능이며 저장되지 않는다. 일반 캠페인에서는 기존 주변 사건도 그대로 진행한다.

## 1일차

관리실 주민 DB의 304호 → 관리실 수도기록 패널 → 3층 304호 소리 녹음 → 1층 우편함 고지서 → PC 보고서.

고지서에는 `4동 404호 / 세대주 윤*** / 세대원 3`, 뒷면에는 `하* 약값`만 표시한다. 처음 읽을 때 SAN -3. 보존하면 사진 증거가 추가되고 ArchiveIntegrity +8, HarinResonance +5. 오류 분류는 단서를 보관하고, 폐기는 증거를 제거하고 RECORD_DEBT +1을 남긴다. 강제 개방은 조사와 별도 상호작용이며 HP -5, BuildingSafety -3을 한 번 적용한다.

보존한 고지서는 다음 날 송장 연도 대조 힌트를 남긴다. 폐기한 경우 2일차 RECORD 계열 후보의 가중치를 50 높인다.

## 3일차

계단으로 4층에 도착해 봉인 씰과 아날로그 높이·압력을 확인한다. 엘리베이터 안의 4S/404 기계 로그를 조사한 뒤 일반 4층 버튼으로 서비스 통로에 진입한다. 메인이 활성 상태일 때 별도 점검 버튼을 숨기며, 추가 층을 생성하지 않는다.

벽의 표시는 `언니 123 / 동생 117`. 기록하면 SAN -5. 씰·아날로그·기계 로그·키 표시를 확보해 보고서에 첨부하면 SPACE_RULE_CONFIRMED와 SAN +3을 받는다. 선택 조사로 관리실 건강기록을 읽었다면 키 표시 옆에서 대조해 `123. 우연이겠지.` 메모를 남긴다.

표시만 따라 통과하면 통로 입구로 되돌아오고, 두 번째부터 Lost와 SAN -10, DISTORTION_DEBT +1을 적용한다. 입구의 변하지 않는 씰을 찾아 자가탈출할 수 있다. Lost 중에는 보고서를 제출할 수 없다. 깊은 점검구는 낙하 위험을 사전 안내하며 HP -12, SAN -3과 추가 기록을 교환한다.

## 5일차

CCTV의 `2009-11-07 02:08` → 4층 현재 방화문 봉인·아날로그 온도/전압 → 서비스 통로 직원 ID → B1 보관 기록의 화재 테이프·근무 기록 → PC 보고서.

현재 맵의 B1에 기록 패널을 배치했으며 기존 구버전 B2 기록실에 들어갈 필요가 없다. 화재 테이프와 직원 ID, 근무 기록을 모두 확보해야 마지막 구조 무전이 확인된다. 무전 종료 위치 흔적까지 조사하면 유해 위치 힌트를 저장한다. 최경태의 승인 서명과 사후 삭제 이력을 모두 확인해야 책임 확인 상태를 저장한다.

첫 화재 테이프 SAN -8, 마지막 구조 확인 SAN -5. 연기가 있는 4층/서비스 통로는 경고 이후 8초마다 HP -1을 소모하며 실제 방화문 제어를 확보하면 멈춘다. 보고서에서 주민 안전 / 기록 백업 / ECHO 추적 / 전체 시스템 유지 우선순위를 선택한다. 선택에 따라 안전·신뢰·기록·방화문 상태와 부채가 바뀐다.

박동식은 과거 구조행동의 ECHO다. 현재의 생존 구조나 쌍방 대화를 추가하지 않는다. `……서우야?`는 고정 스토리 서브퀘스트에 속하므로 이번 메인에는 추가하지 않는다.

## 검증

조사 전 보고서 제출 방지, 증거 반복 획득, 고지서 폐기, 건강기록 대조, Lost 자가탈출, 무전 교차검증, 최경태 기록 대조, 엘리베이터 목적지와 현장 오브젝트 레이캐스트를 자동 테스트한다. 상태는 기존 SaveService의 flag/stat/evidence/case 데이터에 저장된다. 시간 초과 시 기존 사건 수습 절차로 보고서를 제출할 수 있지만, 실제로 확보하지 않은 증거에 기반한 교차검증 상태는 부여하지 않는다.
