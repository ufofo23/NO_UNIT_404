# 협동 테스트 가이드 — 초대 코드 방식

Unity Relay를 씁니다. **IP도 포트포워딩도 필요 없고, 서로 다른 집에 있어도 됩니다.**
방장이 여는 방에 6자리 코드가 붙고, 친구가 그 코드를 입력하면 들어옵니다.

Relay 연결은 이 저장소에서 실제로 검증했습니다 — 진짜 방이 열리고 코드가 발급되는
것까지 자동 테스트(`RelaySessionTests`)로 확인합니다.

---

## 1. 실행

두 개의 인스턴스가 필요합니다. 아무 조합이나 됩니다.

```text
PC A  Unity 에디터 Play    또는  빌드된 NO_UNIT_404.exe
PC B  Unity 에디터 Play    또는  빌드된 NO_UNIT_404.exe
```

한 대에서 둘 다 띄워도 됩니다 (에디터 + 빌드). Relay를 거치므로 같은 PC라도 동작합니다.

빌드: `Tools > NO404 > Build > Windows Development Build`

## 2. 순서

1. 양쪽 다 메인 메뉴로. 오른쪽에 **야간 관리팀** 패널이 있습니다.
2. **방장이 `방 만들기`**. 잠시 뒤 큰 글씨로 코드가 뜹니다.

   ```
   방 코드 — 친구에게 알려주십시오
   N9G69K            [코드 복사]
   ```

3. **친구가 코드를 입력하고 `참가하기`.** 대소문자·공백은 알아서 정리됩니다.
4. 양쪽 패널이 `근무 인원 2 / 4`로 바뀝니다.
5. **방장이 `새 게임`**. 참가자는 누르지 않습니다 — 자동으로 같은 밤에 들어옵니다.

근무 도중에 들어와도 됩니다. 참가자는 진행 중인 밤에 합류합니다.

## 3. 안 될 때

패널이 이유를 한국어로 말해 줍니다.

| 표시 | 뜻 |
|---|---|
| 그런 방이 없습니다 | 코드 오타이거나 방이 이미 닫혔습니다 |
| 방이 가득 찼습니다 | 4명이 상한입니다 |
| 인터넷에 연결되어 있지 않습니다 | 네트워크 문제 |
| 이 빌드에 Unity 프로젝트가 연결되어 있지 않습니다 | 개발자 설정 문제 — 아래 5절 |

에디터에서 `Tools > NO404 > Net > Check Online Services`를 누르면 로그인부터
방 개설까지 한 번에 확인하고 콘솔에 결과를 찍습니다.

## 4. 이 테스트에서 볼 것

v3.0 37.3의 정보 비대칭입니다. 둘이 **같은 것을 보지 못할 때** 대화가 생기는가.

```text
방장    관리실 PC. 주민 명부·출입 기록·CCTV.
참가자  로비로 내려가서 유리 앞에서 방문자를 직접 본다.
```

- **참가자만** 유리 앞 관찰을 봅니다: 손 떨림, 술 냄새, 빈 가방, 백지 클립보드,
  화면 밖에 서 있는 두 번째 사람.
- **방장만** 기록을 대조할 수 있습니다.
- 판정에는 근거 2개가 필요한데 **둘이 서로 다른 절반을 쥐고 있습니다.**

꼭 해보실 것:

1. **문** — 참가자가 문을 열면 방장 화면에서도 열립니다. 요청은 참가자가 보내고
   열어도 되는지는 방장이 판정합니다.
2. **층 출입증을 주기** — 방문자가 실제로 위층으로 갑니다. 관리 PC 홈의
   `건물 안에 있는 사람` 보드에 마지막 확인 위치가 뜨고, **3분 뒤 `위치 불명`**이
   됩니다. 그때 한 명이 찾으러 올라가야 합니다.
3. **`동행 입장`을 주고 일부러 떨어지기** — 30초 뒤 동행이 끊깁니다.
4. **`권한 회수`** — 그 사람은 사라지지 않습니다. 다음 문부터 안 열릴 뿐입니다.

## 5. 개발자 설정 (이미 되어 있음)

이 프로젝트는 Unity Cloud 프로젝트에 연결되어 있고 Relay가 켜져 있습니다.
새 PC에서 처음 열 때 확인할 것:

- `Edit > Project Settings > Services` 에 프로젝트가 연결되어 있는지
- Unity Dashboard 에서 이 프로젝트의 **Multiplayer > Relay** 가 활성인지

지금은 익명 로그인(Anonymous Sign-In)을 씁니다. 계정도 비밀번호도 필요 없습니다.

## 6. 동기화되는 것 / 안 되는 것

**동기화됨**

- 게임 시계
- 서로의 위치·몸 (복도에서 손전등이 보입니다)
- **문 상태**
- 문 앞에 누가 서 있는가, 무엇을 물었고 무엇을 확인했는가
- 관찰 기록(수첩), 압박 수단 소모, 흥분도
- 출입 권한 부여 / 회수, `건물 안에 있는 사람` 보드

**아직 동기화 안 됨**

- **CCTV 화면** — 각자 렌더링합니다. 연출되는 이상 현상이 다르게 보일 수 있습니다.
- **참가자의 홈 화면 업무 목록** — 사건 진행은 방장 쪽에만 있습니다.
- 전화, 매뉴얼 괴현상, 증거 보드, 저장.
- **재접속·호스트 이관** — 방장이 나가면 근무가 끝납니다.

오늘 볼 것은 **문·방문자·추적**이고 그쪽은 양방향으로 붙어 있습니다.
