# 2·4·6일차 퀘스트 가이드

플레이 순서대로 읽는 정리본이다. 각 퀘스트에서 어디로 가서 무엇을 보고, 보고서에서
무엇을 고르면 어떻게 되는지만 적었다. 구현 세부와 날짜 간 연결 전체 표는
[NIGHTS_2_4_6_V51.md](NIGHTS_2_4_6_V51.md), GDD와 다르게 정한 부분은
[GDD/CHANGE_PROPOSALS.md](GDD/CHANGE_PROPOSALS.md) P-01 ~ P-04에 있다.

- 기준: GDD v5.1 11장(2일차), 13장(4일차), 15장(6일차)
- 코드: `SeedContent.V5Mains.cs`(메인), `SeedContent.V51PoolsEven.cs`(서브퀘스트)

## 읽는 법

### 하루가 흘러가는 방식

1. 근무가 시작되면 그날의 퀘스트 5~6개가 정해진다.
   - **메인 퀘스트** 1개 — 항상 나온다.
   - **고정 스토리 서브퀘스트** 1개 — 항상 나온다. 엔딩 장면에 반영된다.
   - **랜덤 서브퀘스트** 3~4개 — 13개 후보 중에서 뽑힌다. 엔딩에는 반영되지 않는다.
2. 퀘스트는 **한 번에 하나씩** 나온다. 지금 퀘스트를 보고해야 다음 퀘스트가 나온다.
3. 나오는 순서: **랜덤 A → 고정 스토리 → 랜덤 B → 메인 → 나머지 랜덤**
4. 모든 퀘스트를 보고하고, 울리는 전화를 받고, 현관의 방문자를 처리하면 퇴근할 수 있다.

### 퀘스트 하나의 흐름

1. 퀘스트가 시작되면 HUD에 확인할 항목이 뜬다.
2. 현장의 소품, CCTV, 전화, 대화로 **필수** 항목을 모두 확인한다.
3. 관리 PC 보고서에서 처리 방식을 고른다.
   - **정답** 선택지는 관련 증거가 있어야 고를 수 있다.
   - 전화·대화로 결정되는 퀘스트는 실제로 한 행동에 맞는 줄만 보고서에 나온다.
4. 03:00이 지나면 남은 필수 항목이 자동 완료되어 보고할 수 있다. 퀘스트 때문에 근무가 막히는 일은 없다.

## 2일차 — 시간과 기록이 어긋나기 시작한다

### 메인 N2-M01 두 명의 서준호

택배기사 서준호가 공동현관에 **두 번** 온다. 첫 번째는 과거가 되풀이된 모습(ECHO)이고,
두 번째가 지금의 진짜 준호다.

1. **첫 번째 호출**에 응답한다. 날씨, 송장 순서 같은 사실을 물어 현재와 맞는지 본다.
2. **두 번째 호출**에 응답한다. 같은 사람이 다시 왔다는 사실 자체가 단서다.
3. **로비를 직접 확인한다**(필수). 아날로그 벽시계와 바닥 발자국이 무엇이 지금인지 말해 준다.
4. CAM-02(선택)는 첫 번째 호출을 들여보냈을 때만 볼 것이 있다.

| 보고 | 조건 | 결과 |
|---|---|---|
| ✅ 확인 후 로비까지만 | 첫 번째는 거절, 두 번째는 로비까지 | 준호 신뢰. 사실 2개 이상 대조했으면 ECHO 규칙 확인 + SAN +3 |
| 🔶 밖에서 기다리게 하고 확인 | 위와 같되 문 밖에 세워 둠 | 신뢰 -3 (배송 지연) |
| 🔶 둘 다 로비로 | 두 호출 모두 로비까지 | 배송은 됨. 규칙은 확인되지 않음 |
| ❌ 층 출입증 발급 | 둘 중 누구든 로비 너머로 | 출입 부채 +1 |
| ❌ 진짜 준호 거절 | 두 번째 호출 거절 | 신뢰 -5, 다음 날 분실 택배 민원 |

### 고정 스토리 N2-R12 2009년 주민의 전화 — 엔딩 반영

1. 퀘스트가 시작되면 관리실 전화가 울린다. 발신자는 **해지된 내선 4-407**이다.
2. 받으면 오래된 엘리베이터 안내음 너머로 "4층에서 연기 냄새가 나요, 404호 쪽이에요"라고 한다.
3. 대답을 하나 고른다.
   - **어디서 전화하시는 거예요?** → "403호요… 11월 7일이잖아요" 하다가 끊긴다.
   - **지금 4층을 확인하겠습니다**
   - **해지된 번호라며 끊는다**
4. (선택) 4층 복도 천장 화재감지기를 확인한다. 정상, 연기 없음.

| 보고 | 조건 | 결과 |
|---|---|---|
| ✅ 통화를 이어가며 위치를 물었다 | 위치를 물었을 때 | 기록보존 +4, 하린공명 +3, SAN -6, **엔딩에 2009년 통화 장면** |
| ✅ 끊고 4층을 직접 확인했다 | 위치를 묻지 않음 + 감지기 확인 | 하린공명 +3, SAN -3 |
| 🔶 통화를 이어가지 않았다 | 위치를 묻지 않음 | 변화 없음 |

전화를 놓쳐도 통화 기록이 남아 보고할 수 있다.

## 4일차 — 기록이 사람의 이름을 부르기 시작한다

### 메인 N4-M01 404 주민 DB 침투

주민 DB 동기화 뒤에 있을 수 없는 404호 행이 생긴다. 회장 최경태가 전화로 오류이니
지우라고 지시한다.

1. 관리 PC에서 **주민 DB 앱을 연다**(필수).
2. **404호 행을 연다**(필수). 내 이름이 있다. SAN -8.
3. **B1의 종이 주민대장을 확인한다**(필수). 행을 본 뒤라면 SAN +3.
4. 404호 행에서 처리 버튼을 누른다: **출력 / 반출 / 삭제**, 또는 아무것도 하지 않는다. 한 번만 할 수 있다.
5. 보고 직후 기억 연출(CIN-N4, SAN -4)이 나온다.

| 보고 | 조건 | 결과 |
|---|---|---|
| ✅ 출력해서 보관 | 출력 버튼 | 하린 기록 보존, 기록보존 +15, 회장경계 +15, 하린공명 +10 |
| ✅ 외부로 반출 | 반출 버튼 | 하린 기록 보존, 기록보존 +12, 회장경계 +25, 하린공명 +10 |
| 🔶 그대로 둠 | 버튼을 누르지 않음 | 하린 기록 보존, 회장경계 +5, 하린공명 +10 |
| ❌ 삭제 | 삭제 버튼 | 기록 부채 +2, 기록보존 -15. 다음 날 종이 대장이 대체 증거로 주어짐 |

하린 기록이 보존되면 6일차 엔딩에서 그녀의 이름이 명단에 **인쇄된다**. 아니면 서우가 손으로 적는다.

### 고정 스토리 N4-R10 선자의 증언 — 엔딩 반영

1. 3층 **303호 문을 두드린다**. 선자 할머니와 대화가 시작된다.
2. 그날 밤 복도의 아이 둘과 관리직원 박동식을 이야기한다. 대답을 하나 고른다.
   - **녹음해도 될까요? 천천히 말씀해 주세요.**
   - **시간이 없어요. 어디서 보셨는지만요.**
   - **최경태 회장도 그날 밤 있었나요?**

**전체 증언 조건** — 셋 중 하나만 충족하면 된다.
- 1일차 방문간호사(N1-R01)를 제대로 들여보냈다
- 같은 밤 R01에서 303호를 직접 찾아갔다
- 주민 신뢰가 60 이상이다

| 보고 | 조건 | 결과 |
|---|---|---|
| ✅ 동의를 받고 녹음 (전체) | 녹음 동의 + 전체 증언 조건 | 기록보존 +6, 신뢰 +3, **엔딩에 선자 전체 증언 장면** |
| ✅ 동의를 받고 녹음 (부분) | 녹음 동의 + 조건 미충족 | 기록보존 +6, 신뢰 +3 |
| 🔶 재촉했다 | 재촉 | 부분 증언 |
| 🔶 최경태 이야기부터 | 회장 질문 | 부분 증언, 신뢰 -2, 회장 관련 단서 |
| 🔶 증언을 듣지 못했다 | 방문하지 않음 | 증언 없음 |

증언이 남으면(부분이어도) 5일차 N5-R13 무전 교차검증의 증인이 된다.

## 6일차 — 마지막 근무

### 메인 N6-M01 404호는 있었습니다

1. **404호에 들어간다**(필수). 로비의 404 열쇠와 6일차 유압 절단기가 필요하다. SAN -5. 5일차에 방화문을 열어 두었다면 연기로 HP -10.
2. **2009년 마지막 구조 장면을 본다**(필수). 박동식이 아이를 내보내고 다시 들어가는 장면이 그가 쓰러진 자리에서 끝난다. SAN -6.
3. (선택) **유해 수습**과 (선택) **원본 장부 확보**는 시간을 다툰다. 먼저 한 쪽을 하면 다른 쪽은 사라진다.
   - 균형 루트: 6일차 시작 시 건물 안전 60 이상이고 방화문이 SAFE면 둘 다 가능하다.
4. 보고서에서 증거를 **경찰 / 언론 / 주민** 중 한 곳으로 보낸다. 보내는 순간 근무가 끝나고 엔딩으로 간다.

엔딩은 하나다. 여섯 밤의 선택은 엔딩 안의 장면(컷)으로만 달라진다. HP가 0이면 엔딩이 없다.

### 고정 스토리 N6-R05 도면에 없는 방문 — 엔딩 반영

메인보다 먼저 나온다. 열쇠와 절단기만 있으면 메인 없이도 404호에 들어갈 수 있다.

1. 404호 안 서쪽 벽의 **이름 없는 문패를 확인한다**(필수).
2. (선택 행동) **손잡이로 문을 연다** — SAN -10, 기억이 먼저 들어온다.
3. (선택) **문 앞 빨간 실내화 한 짝을 줍는다**.

| 보고 | 조건 | 결과 |
|---|---|---|
| ✅ 문을 열었다 | 문을 열었을 때 | 하린공명 +3, **엔딩에 하린의 방 기억 장면** |
| ✅ 열지 않고 기록했다 | 문을 열지 않음 | SAN -3, 엔딩은 실내화 장면 |
| 🔶 실내화를 챙겼다 | 문을 열지 않음 + 실내화 | 하린공명 +3, SAN -5, 엔딩은 실내화 장면 |
